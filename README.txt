RS ASSESSORIA — LANDING PAGE
================================

Arquivos:
- index.html: estrutura e conteúdo da landing page
- style.css: estilos responsivos
- assets/logo-rs.jpg: logo fornecido, com limpeza básica
- assets/ronilson-rs.jpg: foto fornecida para a página

COMO PUBLICAR NO GITHUB E VERCEL
1. Extraia o ZIP.
2. Envie index.html, style.css, README.txt e a pasta assets para a raiz do repositório GitHub.
3. No Vercel, importe o repositório.
4. Como é um site estático em HTML/CSS, não precisa de framework nem comando de build. Se houver configuração manual, deixe Framework Preset como Other, Build Command vazio e Output Directory vazio (raiz do projeto).
5. Faça o deploy.

NOTAS
- Todos os botões de contato direcionam ao WhatsApp informado.
- O botão flutuante do WhatsApp permanece no canto inferior direito.
- O FAQ usa o elemento nativo <details>, sem JavaScript.
- A tipografia do Google Fonts requer conexão com a internet; há fontes de fallback.
- Confirme o conteúdo e os depoimentos antes de publicar.
